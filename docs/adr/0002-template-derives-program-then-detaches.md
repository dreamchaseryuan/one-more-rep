# 内置 Template 派生 Program 之后即与 Template 脱钩

内置训练模板（Template）是**只读的起点**。使用者选用某个模板时，它被复制成一份归使用者所有的
Program，之后两者再无关联：模板随版本更新，也不会影响任何已有的 Program。

没做「模板有更新，是否合并」这个提示。三方 diff（使用者的版本 / 旧模板 / 新模板）需要把 base 版本
也存下来，还要一套合并 UI；而本项目是单用户自用工具，模板改动是和使用者讨论后直接做的，
提示机制的收益接近零，成本却不低。比起「合并」，静默覆盖使用者的编辑是更糟的结果，
所以自动套用更新这个选项直接排除。

**推论**：Program 完全归使用者，Template 只在「选用」的那一刻起作用。
**代价**：模板改进无法惠及已有 Program；使用者若想拿到新版本，得重新从模板选用一次。
